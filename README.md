# Duolingo-Checkin

多邻国（Duolingo）每日自动打卡脚本。单个 Python 文件，零依赖，可以部署在[青龙面板](https://github.com/whyour/qinglong)、服务器 cron 或本机定时任务中运行。

## 功能

- **自动续连胜**：今天还没学习时，完成一次通用练习续上连胜（约 +13 XP）；今天已经续过则跳过
- **补齐每日任务**：把所有可能抽到的每日任务指标补到刚好达标，只补差额
- **月度挑战达成后停手**：本月月度挑战完成后不再处理每日任务，下个月自动恢复
- **运行报告**：结束时在日志中输出本次结果和账号状态
- **多账号**：一次运行处理多个账号

> [!WARNING]
> 本脚本使用多邻国的非公开接口，**违反多邻国服务条款**，存在账号被限制或封禁的风险。请仅用于自己的账号，并自行承担后果。
>
> 本项目与 Duolingo, Inc. 无任何关联。

## 环境要求

- Python 3.9 或更高版本
- 能访问 `www.duolingo.com` 和 `goals-api.duolingo.com`

不需要安装任何第三方库。

## 获取 JWT

JWT 是你登录多邻国网页版后的身份令牌，脚本靠它代表你的账号发请求。

1. 在浏览器打开 [duolingo.com](https://www.duolingo.com) 并登录
2. 按 `F12`（Mac 上按 `Cmd + Option + I`）打开开发者工具，切到 **Console（控制台）**
3. 输入下面这行并回车：
   ```js
   document.cookie.match(/jwt_token=([^;]+)/)[1]
   ```
4. 复制输出的那一长串，不要带引号

如果控制台报错，也可以在 **Application → Cookies → https://www.duolingo.com** 里找到 `jwt_token`，直接复制它的值。

> [!CAUTION]
> JWT 等同于你的登录凭证，**不要发给任何人**，也不要提交到 Git 仓库。在浏览器里退出登录会让它失效，失效后需要重新获取。

## 部署

### 青龙面板

1. **添加脚本**：在 **脚本管理** 中新建 `duolingo_checkin.py`，粘贴本仓库同名文件的内容。也可以在 **订阅管理** 中订阅本仓库。
2. **添加环境变量**：在 **环境变量** 中新建 `DUO_JWT`，值为你的 JWT。多个账号用换行或 `&` 分隔。
3. **添加定时任务**：在 **定时任务** 中新建：

   | 字段 | 值 |
   |---|---|
   | 命令 | `task duolingo_checkin.py` |
   | 定时规则 | `30 20 * * *`（每天 20:30，可按需修改） |

4. **先预览再启用**：临时添加环境变量 `DUO_DRY_RUN=1`，手动运行一次，查看日志确认无误后删除该变量。预览模式不会提交任何数据。

### 命令行 / cron

```bash
export DUO_JWT='你的jwt'
python3 duolingo_checkin.py --dry-run   # 先预览
python3 duolingo_checkin.py             # 正式运行
```

用系统 cron 每天 20:30 运行：

```cron
30 20 * * * DUO_JWT='你的jwt' /usr/bin/python3 /path/to/duolingo_checkin.py >> /path/to/checkin.log 2>&1
```

> [!IMPORTANT]
> cron 按**运行环境的时区**触发，多邻国则按**账号时区**切换日期。如果运行环境是 UTC（容器里很常见），`30 20 * * *` 对应的是北京时间第二天 4:30。请确认两者一致，或者换算后再填定时规则。

## 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `DUO_JWT` | ✅ | 账号 JWT，多个用换行或 `&` 分隔 |
| `DUO_TZ` | | 时区名，如 `Asia/Shanghai`。默认使用账号资料里设置的时区，一般不需要改 |
| `DUO_QUEST_SKIP` | | 不补的指标前缀，逗号分隔，如 `CHESS_,MATH_`。不设置时按账号已加入的课程类型自动判断；设为空字符串表示全部补齐 |
| `DUO_NO_QUEST` | | 设为 `1` 只打卡，不处理每日任务 |
| `DUO_DRY_RUN` | | 设为 `1` 只预览，不提交任何数据 |

命令行参数 `--dry-run`、`--no-quest` 与对应的环境变量效果相同。

## 运行报告示例

```
多邻国打卡 ✅
✅ your_username
打卡：✅ 成功（第 1 次）
每日任务：✅ 已补齐 38 个指标
🔥 连胜 365 天（今天已续 ✓）
🎯 下一个里程碑 400 天，还差 35 天
📈 今日 63 XP · 学习 17 分钟
🏅 月度挑战 42/65
⭐ 总 XP 123,456（+13）
💎 宝石 5,000
```

所有账号都成功时退出码为 `0`，任一账号失败时为 `1`，没有配置账号时为 `2`。

## 工作原理

### 打卡

读取账号资料中最后一次续连胜的日期。如果不是账号时区的今天，就创建一次 `GLOBAL_PRACTICE` 练习会话并提交为完成，失败时最多重试 3 次。

这种会话不关联课程路径上的任何关卡，**不会改变你的课程进度**。

### 每日任务

- App 会按你当前学习的课程从任务池中随机抽取每日任务，换课程或换设备都可能不同，因此无法预知今天是哪几个
- 但服务器端的进度是全账号按指标（如 `XP`、`LESSONS`）共享计数的
- 所以脚本对任务池中的每个指标，取所有每日任务的最高目标值，减去当前进度，只上报差额。这样无论抽到哪个任务都能完成
- 目标值按账号难度档位取 `difficultyTiers[difficulty - 1]`；同一任务有多个版本时取最新版本
- 已达标时不发送任何请求，重复运行是安全的

### 时区

多邻国的任务接口只认 `Asia/Shanghai` 这类 IANA 时区名，传 `UTC+08:00` 会得到错误时间段的数据。脚本默认使用账号资料里设置的时区，所以在 UTC 时区的容器里也能正确判断"今天"。
